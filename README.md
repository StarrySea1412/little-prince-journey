# 小王子 · 星间漫游

一场献给曾经是孩子的大人的旅行：八章互动旅程、原创中文重述、六幅原创水彩插画、一片可以点亮的星空。单页零依赖，**手机与电脑都可以进入**。

**[开始旅程 →](https://starrysea1412.github.io/little-prince-journey/)**

<img src="assets/fig-planet.webp" width="420" alt="水彩画：漂浮在星空中的小小星球，两座火山、玻璃罩里的红玫瑰"/>

旅途中的小互动：给玫瑰浇一点水、拔掉猴面包树的幼苗、点亮六颗大人的星球、耐心地驯养一只狐狸、摇起辘轳打一桶水、让星星笑出声。

> 改编自安托万·德·圣埃克苏佩里《小王子》（1943）。全部文字为**原创重述**，全部插图为**原创绘制**（AI 辅助生成），向原作致敬。
>
> 灵感来自 [littleprince.dev](https://littleprince.dev/) 的 Unity 互动版；本作是网页原生的独立实现，不含其任何素材，并额外支持移动端。
